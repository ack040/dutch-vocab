# Chess Opening Traps

A self-contained HTML page with 50 named opening traps: 25 you can spring as White, 25 as Black.
Every line is checked for legality by the built-in engine and every trap was verified with Stockfish.

**Deliverable:** `dist/chess-traps.html`. One file, no CDN, no network access. Drop it on any static host.

## What it does

- **Explorer.** Pick your colour. Enter each move as it is played: tap a piece and its target square,
  type it (`e4`, `nf3`, `O-O`, `e2e4` and `3.Bc4` all work), or tap a suggested move. Only traps
  *you* can spring are shown; nothing warns you about your own mistakes.
  Traps are matched by **position**, so a different move order into the same position still counts.
  Blue arrow: your book move. Red arrow: the losing move the opponent might play. Green arrow and alert:
  the move that punishes it, playable with one tap. Back/Forward (and the arrow keys) keep the rest of
  the game, promotion has a picker, and the game you are entering survives a reload.
- **Library.** All 50 traps with a thumbnail of the critical position, filters for side and outcome,
  search, sorting, and a learned counter.
- **Viewer.** Step through any line with notes, the mistake in red and the refutation in green, plus
  Stockfish's numbers: what the position is worth if the opponent defends correctly, right after
  their mistake, and at the end of the line. Traps whose set-up is objectively dubious are tagged
  **Risky**. **Quiz me** plays the opponent's moves and asks you to find yours; a clean run marks the
  trap as learned. Every position links to Lichess analysis.

## Layout

```
src/engine.js         0x88 engine: legal moves, SAN parse/render, FEN, position keys
src/traps-white.js    25 White traps
src/traps-black.js    25 Black traps
src/evals.js          Stockfish numbers, generated by tools/audit.js
src/index.html, src/style.css, src/app.js   the page
src/validate.js, src/check.js               mechanical checker
src/build.js          inlines everything into dist/chess-traps.html
tools/audit.js        Stockfish audit and quality gate (needs Stockfish installed)
tools/ui-test.js      browser tests (needs Playwright with Chromium)
```

## Commands

```sh
node src/check.js        # legality, canonical SAN, mate and material claims
node tools/audit.js      # Stockfish depth 20: quality gate, regenerates src/evals.js
node src/build.js        # writes dist/chess-traps.html
node tools/ui-test.js    # 67 browser checks, including a clean quiz run of all 50 traps
```

## Quality gate

`tools/audit.js` fails a trap when the marked blunder is the engine's best move or costs under half
a pawn, when the refutation is more than 0.6 worse than the engine's choice, or when the line does not
end clearly better (or mated) for the trapping side. It warns on modest traps and on inaccurate
follow-up moves. The current library: 0 failures, 6 warnings (modest but famous traps such as the
Fried Liver), 5 risky set-ups.
